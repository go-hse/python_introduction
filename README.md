# Python Beispiele 

Die Beispiele dienen als Basis für den Kurs "Einführung in die Programmierung mit Python" an der Hochschule Esslingen.

Version 3.0 erstellt für Cyberweek Sep. 2025
Version 2.0 erstellt für Cyberweek Feb. 2025
Version 1.0 erstellt am 14.08.2024


### Installation für Windows

Nach der Installation von Python (inkl. Setzen der PATH-Umgebungs):

```batch
pip install https://github.com/go-hse/python_introduction/archive/refs/heads/main.zip

python-intro-copy

```

Installiert werden:
- Python inkl. Jupyter
- Entwicklungsumgebung VS Code 
- Versionsmanagement-Werkzeug Git
- Dieses Repository mit Jupyter-Notbooks und Beispielen

### Tipps
Falls jupyter nach einem Token fragt:
```
jupyter server list
```
